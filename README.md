# Digital Wellbeing

A modern Windows desktop application for monitoring, managing, and improving digital habits with real-time screen time analytics, parental controls, and productivity tools.

## Overview

Digital Wellbeing is a high-quality WPF-based desktop application designed to help users track app usage, reduce screen overuse, and maintain healthier digital habits. The application runs fully offline, does not collect telemetry, and supports Windows 7 through Windows 11.
